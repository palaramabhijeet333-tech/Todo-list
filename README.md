# 📝 Interactive To-Do List App

A lightweight, clean, and responsive To-Do List application built using vanilla HTML5, CSS3, and JavaScript. It helps users manage daily tasks efficiently with real-time progress tracking.

## 🚀 Features

* **Add, Edit & Delete Tasks:** Easily create new tasks, modify existing ones, or remove finished items[cite: 2].
* **Task Completion:** Mark tasks as done with interactive toggle styling[cite: 2, 3].
* **Progress Tracking:** Visual progress bar and live counters showing completed vs. total tasks[cite: 1, 2].
* **Local Storage Persistence:** Keeps your tasks saved automatically even after refreshing or closing the browser[cite: 2].
* **Input Validation:** Built-in error handling to prevent adding empty tasks[cite: 1, 2].
* **Keyboard Support:** Quickly add tasks by pressing the `Enter` key[cite: 2].

## 🛠️ Built With

* **HTML5:** Semantic page structure[cite: 1].
* **CSS3:** Custom modern UI styling, animations, and dark-themed background[cite: 3].
* **JavaScript (ES6):** DOM manipulation, event listeners, and localStorage API[cite: 2].

## 💻 How to Run

1. Clone or download the repository files.
2. Open `index.html` in any web browser.
